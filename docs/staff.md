# スタッフを載せたい

<p class="lead">スタッフの写真とプロフィールを、ホームページの「スタッフ」に載せます。</p>

## 新しく載せる

<ol class="steps" markdown>
<li markdown="block">
左のメニューで「スタッフ」→「スタッフを追加」を押します。

![左のメニュー](img/staff/menu.webp){ .shot }
</li>
<li markdown="block">
いちばん上の欄に、名前を入れます。

![名前の欄](img/staff/title.webp){ .shot }
</li>
<li markdown="block">
「スタッフ基本情報」に、ローマ字の名前や役職を入れます。分からない欄は空欄でかまいません。

![スタッフ基本情報](img/staff/basic.webp){ .shot }
</li>
<li markdown="block">
右側の「スタッフ分類」で、STYLIST などを選びます。**選ばないと、スタッフの一覧に出ません。**

![スタッフ分類](img/staff/category.webp){ .shot }
</li>
<li markdown="block">
右下の「アイキャッチ画像を設定」を押して、写真を選びます。選び方は[ヘアスタイル](style.md)と同じです。

![アイキャッチ画像](img/staff/photo.webp){ .shot }
</li>
<li markdown="block">
右上の「公開」を押します。

![公開ボタン](img/style/publish.webp){ .shot }
</li>
</ol>

!!! note "入れなくてよいもの"
    「Staff Detail」のコメントやプロフィールは、書いた項目だけがページに出ます。空欄の項目は出ません。<br>
    「SEO設定」は触らないでください。

## 店舗トップでの写真の位置を変える

公開したあと、同じ画面の「店舗トップ画像」で、店舗トップに出る写真の位置と大きさを変えられます。動かしたら「更新」を押します。

![店舗トップ画像](img/staff/top-photo.webp){ .shot }
