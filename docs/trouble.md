# うまくいかないとき

## 公開したのに店舗トップに出ない

店舗トップには、選んだものだけが出ます。[店舗トップに載せるものを選びたい](top-items.md)の手順で、チェックを入れてください。

## ヘアスタイルの写真が出ない

「ギャラリースライダーを表示する」にチェックが入っているか確かめてください（[ヘアスタイルを載せたい](style.md)の手順 3）。

## 新しいスタッフが一覧に出ない

「スタッフ分類」で STYLIST などを選んでいるか確かめてください（[スタッフを載せたい](staff.md)の手順 4）。

## 保存しても「保存しました」と出ない

「FAQ」「ご予約・CTA」「店舗コンセプト」の画面は、保存しても知らせが出ません。保存はできているので、ホームページで確かめてください。

## 直したのにホームページが変わらない

ホームページを開いている画面で、再読み込み（Windows は F5、Mac は ⌘ と R）をしてください。
