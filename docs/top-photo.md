# 店舗トップの写真を変えたい

<p class="lead">店舗トップのいちばん上に大きく出る 3 枚の写真を変えます。</p>

<ol class="steps" markdown>
<li markdown="block">
左のメニューの「店舗トップ」を開きます。
</li>
<li markdown="block">
「ファーストビュー」で、変えたい写真の「画像を変更」を押して、写真を選びます。

1. 横長の写真（横 1450 × 縦 860 くらい）。パソコンで見たときに出ます。
2. 「スマホ用（任意）」の縦長の写真（横 1080 × 縦 1620 くらい）。スマホで見たときに、上の写真の代わりに出ます。空欄でかまいません。空欄のときは、上の写真の真ん中を切り抜いて出します。

![ファーストビュー](img/top/fv.webp){ .shot }
</li>
<li markdown="block">
いちばん下の「店舗トップ設定を保存」を押します。

![保存ボタン](img/top/save.webp){ .shot }
</li>
</ol>
