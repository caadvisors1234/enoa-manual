# やってはいけないこと

<p class="lead">ホームページが崩れたり、表示されなくなったりする操作です。</p>

## 固定ページの状態や URL を変える

「固定ページ」のページ（メニュー、アクセスなど）を下書きに戻したり、URL（パーマリンク）を変えたりすると、そのページが表示されなくなります。固定ページは削除できない設定にしています。

## 使わない欄に入力する

ヘアスタイルの画面にある「カスタムCSS」「ギャラリーページの設定」「meta title と meta description」と、各画面の「SEO設定」は触らないでください。

## 保存する前に「座標を再取得」を押す

「店舗情報・アクセス」の「座標を再取得」を押すと、保存していない変更が消えます。押す必要はありません。

## 一括登録で同じ名前を使う

「メニュー」→「一括登録」で、同じカテゴリーにある名前のメニューを貼り付けると、新しく作らずに上書きします。
